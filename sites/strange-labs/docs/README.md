# Strange Labs docs

Strange Labs is where Solemn keeps the tools he builds for making art on Bitcoin. They are free for anyone to use.

These pages explain how each tool works. Start with the one you want:

* **[Gl1tch CC0mposer](gl1tch-composer/README.md)**: stack gl1tches with your own inscriptions and export one file that is ready to inscribe.

More tools will get their own pages here as they are finished.
