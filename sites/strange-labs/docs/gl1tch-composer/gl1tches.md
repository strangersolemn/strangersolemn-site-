# The CC0 gl1tches

Press **+ CC0 Gl1tch** to open the picker. Tap any gl1tch to try it on the canvas, then press **Use this one**. To swap a gl1tch later, select its layer and press **Change gl1tch**.

The picker has two kinds.

## GL1TCH ENG1NE: fifteen gl1tches with controls

One small inscription on Bitcoin (9.6 KB) draws all fifteen:

| | | | | |
|---|---|---|---|---|
| BARS | SN0W | PULSE | DASH | M0SH |
| X0R | S0RT | VHS | L1NES | B1TS |
| QUAD | MAZE | M01RE | D0TS | BURST |

Select an engine layer and these controls appear on the right:

| Control | What it does |
|---|---|
| **Main, Second, Background** | The three colours. Tap a swatch or pick any colour. |
| **See-through / Solid background** | See-through lets the layers under it show between the gl1tch. Solid fills the background colour. |
| **Speed** | How fast it moves. 0 stops it. |
| **Density** | How much of the picture the gl1tch covers. |
| **Pixel size** | Small for fine noise, big for chunky blocks. |
| **RGB split** | Pulls the red, green and blue apart, like a broken screen. |
| **Scanlines** | Old TV lines over the top. |
| **Tear** | Rows that slip sideways now and then. |
| **Lock seed** | Freezes the pattern, so it looks the same every time it loads. Type a number to choose which pattern. |
| **Seconds between mode changes** | Above 0, the gl1tch jumps to a new one of the fifteen every so many seconds. |

## GL1TCH C0DE5: the cursed originals

Below the engine are **#01, #02 and #03**, three of the original GL1TCH C0DE5 pieces, the p5.js gl1tches the collection started with. They play as they were made: no colour controls. You can still size, move, recolour and blend them like any layer (see [Edit a layer](layers.md)).

> **Tip:** stack an engine gl1tch and a cursed one, and set the top one to **Screen**. Both show through each other.

Every gl1tch here is CC0. Use them in anything, on Bitcoin or off it.
