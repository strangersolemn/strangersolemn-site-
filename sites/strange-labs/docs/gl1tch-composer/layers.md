# Edit a layer

Tap a layer in the list on the left to select it. Its controls open on the right (on a phone, press **Edit layer**).

## Fit and position

| Control | What it does |
|---|---|
| **Fit** | Shows the whole layer inside the square. |
| **Fill** | Fills the square and crops the edges. |
| **Stretch** | Stretches it to the square. |
| **Size** | 10% to 300%. |
| **Move left / right, Move up / down** | Slides it around the square. |
| **Reset** | Puts all four back. |

## Effects

| Control | What it does |
|---|---|
| **Hue** | Turns every colour round the colour wheel. |
| **Saturation** | 0% is black and white, 200% is loud. |
| **Contrast** | Pushes darks and lights apart. |
| **Opacity** | How see-through the layer is. |
| **Blend** | How the layer mixes with the ones under it. |

## Blend modes

There are sixteen: Normal, Multiply, Screen, Overlay, Darken, Lighten, Color dodge, Color burn, Hard light, Soft light, Difference, Exclusion, Hue, Saturation, Color and Luminosity.

The ones you'll use most:

* **Screen** drops black. Use it for art on a black background, like the skull from CORRUPTED.
* **Multiply** drops white. Use it for art on a white background.
* **Hard light** is what CORRUPTED itself uses on its gl1tch layers: strong, punchy colour.
* **Difference** flips colours where layers overlap. Good for chaos.

## Order and removing

**↑ Up** and **↓ Down** move the layer in the stack. **Delete** removes it.
