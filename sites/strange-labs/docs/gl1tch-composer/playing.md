# How it plays

The four buttons under the canvas set how the finished piece behaves. They only change the **CC0 gl1tch** layers. Your own art always stays on screen.

| Setting | What the inscribed piece does |
|---|---|
| **All** | Every gl1tch layer shows at once. |
| **Click** | One gl1tch at a time. Click or tap the piece (or press Enter or Space) to go to the next. |
| **Block** | One gl1tch at a time. It moves to the next one on every new Bitcoin block, about every ten minutes. |
| **Chance** | Each inscription shows one gl1tch, picked from its own inscription ID. |

## Chance, in more detail

Chance is for editions. Export one file and inscribe it many times: each copy gets a different inscription ID, and the ID decides which gl1tch that copy shows. It never changes after that, so every copy keeps its own look.

When you pick **Chance**, a **Chance weights** box opens:

* Give each gl1tch a weight. Higher means more likely. Set a rare one low.
* **Test id** is a made-up inscription ID, so you can see what one copy would look like. Press **Reroll** to try another.

> **Tip:** Click, Block and Chance need at least two gl1tch layers to have something to switch between.
