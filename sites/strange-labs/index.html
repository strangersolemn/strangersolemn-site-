Gl1tch CC0mposer

On Bitcoin

Live from Bitcoin. Tap a number to switch gl1tch.

Stack gl1tches with your own inscribed images and HTML pieces, tune each layer, and export one HTML file that is ready to inscribe.

Open the CC0mposer Open on ordinals.com ↗
  1. Add layers. 15 gl1tches from the new engine, the cursed originals, or any inscription ID of yours.
  2. Tune them. Colour, speed, hue, contrast, opacity and blend, layer by layer.
  3. Pick how it plays. All at once, on click, on every new block, or one by chance.
  4. Export. One small HTML file. Inscribe it and it runs from Bitcoin for good.

02

GL1TCH TOOLS

In your browser

The kit I use to get art ready to inscribe. Seven small tools on one page. Your files stay on your device.

Open GL1TCH TOOLS

  • GIF to sprite sheet

    Turns a GIF into one AVIF grid of its frames.

  • Sandbox

    Write HTML and see it run. Capture HD frames and make a GIF.

  • SVG code

    Drop in an SVG, see it, and copy its code.

  • SVG animate

    Drop in SVG frames and get one animated SVG that swaps between them.

  • PNG to AVIF

    Shrinks PNGs to AVIF, a batch at a time.

  • Minify

    Strips comments and spaces out of JavaScript.

  • Base64

    Turns any file into a data link you can paste into code.
